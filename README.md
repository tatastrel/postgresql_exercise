# 🐘 postgresql_exercise
Решение практических задач по PostgreSQL из тренажеров и курсов.

## 🎯 Цель проекта
* **Продемонстрировать навыки** составления SQL-запросов.
* **Закрепить на практике** теоретическую базу по администрированию и оптимизации PostgreSQL.

## 📝 Темы упражнений
В рамках данного курса/репозитория отрабатываются следующие темы:
**Основы SQL:** Фильтрация (WHERE), сортировка (ORDER BY), базовые функции.
**Связи и объединения:** INNER JOIN, LEFT/RIGHT JOIN, FULL OUTER JOIN.
**Агрегация данных:** GROUP BY, HAVING, агрегатные функции (SUM, AVG, COUNT).

## 🛠️ Стек технологий
* **СУБД:** PostgreSQL 
* **Инструменты:**  DBeaver
